# SSO・メール認証システム設計書

## アーキテクチャ概要

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐     ┌─────────────┐
│   Next.js   │────▶│   FastAPI    │────▶│  Supabase   │     │   Stripe    │
│  (Frontend) │     │  (Backend)   │     │    Auth     │     │   Webhook   │
└─────────────┘     └──────────────┘     └─────────────┘     └─────────────┘
       │                    │                     │                    │
       ▼                    ▼                     ▼                    ▼
┌─────────────┐     ┌──────────────┐     ┌─────────────┐     ┌─────────────┐
│   Cookie    │     │     JWT      │     │ PostgreSQL  │     │   Stripe    │
│   Session   │     │  Validation  │     │  Database   │     │     API     │
└─────────────┘     └──────────────┘     └─────────────┘     └─────────────┘
```

## 1. 認証の責任範囲
- **Next.js**: 認証, ロールベースでUIの表示制御(認可)
- **FastAPI**: 認証の検証, ロールベースでAPIのアクセス制御(認可)
- **Supabase Auth**: ユーザー管理, 認証トークンの発行

## 2. セキュリティ要件

### 2.1 認証・認可
- **PKCE (Proof Key for Code Exchange)** を使用したOAuth 2.0フロー
- **セッション管理**: HTTPOnly Cookieでセッション管理
- **CSRF対策**: SameSite=Strict Cookie + CSRFトークン
- **XSS対策**: Content Security Policy (CSP) の実装

### 2.2 パスワード要件
- 最小8文字以上
- 大文字・小文字・数字を含む
- 過去5回のパスワードの再利用禁止
- パスワード強度メーター表示

## 3. フロー

### 3.1 ユーザー登録（Email & パスワード）

![alt text](../images/ユーザ登録フロー.png)

```mermaid
sequenceDiagram
    participant User
    participant Frontend (Next.js)
    participant Supabase Auth
    participant Backend (FastAPI)
    participant Database
    participant Audit Service

    User->>Frontend (Next.js): メール&パスワード入力
    Frontend (Next.js)->>Frontend (Next.js): 入力検証
    Frontend (Next.js)->>Supabase Auth: signInWithPassword()
    
    alt 認証失敗
        Supabase Auth-->>Frontend (Next.js): エラー（401）
        Frontend (Next.js)->>Database: 失敗回数を記録
        Frontend (Next.js)-->>User: エラーメッセージ表示
    else 認証成功
        Supabase Auth->>Database: セッション作成
        Supabase Auth-->>Frontend (Next.js): JWT Token + User Info
        Frontend (Next.js)->>Frontend (Next.js): Cookieに保存
        Frontend (Next.js)->>Backend (FastAPI): 監査ログ記録API
        Backend (FastAPI)->>Audit Service: ログイン記録
        Frontend (Next.js)->>Frontend (Next.js): ユーザー情報取得
        Frontend (Next.js)-->>User: ダッシュボードへリダイレクト
    end
```

### 3.2 ユーザー登録（SSO）

![alt text](../images/ユーザ登録フロー2.png)

```mermaid
sequenceDiagram
    participant User
    participant Frontend
    participant Supabase Auth
    participant Google OAuth
    participant Database
    participant Backend

    User->>Frontend: 「Googleでログイン」クリック
    Frontend->>Supabase Auth: signInWithOAuth('google')
    Supabase Auth->>Google OAuth: 認証リダイレクト
    User->>Google OAuth: Googleアカウントで認証
    Google OAuth->>Supabase Auth: 認証コード返却
    Supabase Auth->>Google OAuth: アクセストークン取得
    Supabase Auth->>Database: ユーザー作成/更新
    Supabase Auth->>Frontend: コールバックURL + Token
    Frontend->>Frontend: トークン保存
    Frontend->>Backend: ユーザー情報同期
    Frontend->>User: ダッシュボードへ
```

### 3.3 ログイン中

![alt text](../images/ユーザ登録フロー3.png)

```mermaid
sequenceDiagram
    participant Browser as ブラウザ
    participant NextJS as Next.js
    participant Middleware as Next.js Middleware
    participant AuthContext as AuthContext
    participant Supabase as Supabase Auth
    participant FastAPI as FastAPI
    participant DB as Database

    Browser->>NextJS: ページアクセス (/)
    NextJS->>Middleware: リクエスト処理
    
    Note over Middleware: 1. Cookieからセッション確認
    Middleware->>Supabase: セッション検証
    alt セッションが有効
        Supabase-->>Middleware: ユーザー情報
        Middleware->>NextJS: リクエスト継続
    else セッションが無効/なし
        Middleware->>Browser: 必要に応じてリダイレクト
    end
    
    NextJS->>AuthContext: コンポーネントマウント
    AuthContext->>Supabase: getUser() / getSession()
    
    alt 認証済み
        Supabase-->>AuthContext: セッション情報
        AuthContext->>FastAPI: GET /api/auth/me
        Note over FastAPI: トークン検証
        FastAPI->>DB: ユーザー詳細取得
        DB-->>FastAPI: プロファイル、ロール、連携情報
        FastAPI-->>AuthContext: 完全なユーザー情報
        AuthContext->>Browser: 認証済みUI表示
    else 未認証
        AuthContext->>Browser: 未認証UI表示
    end
```
