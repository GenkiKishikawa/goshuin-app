## 1. セキュリティ要件

### 1.1 認証・認可
- **PKCE (Proof Key for Code Exchange)** を使用したOAuth 2.0フロー
- **セッション管理**: HTTPOnly Cookieでセッション管理
- **CSRF対策**: SameSite=Strict Cookie + CSRFトークン
- **XSS対策**: Content Security Policy (CSP) の実装

### 1.2 パスワード要件
- 最小8文字以上
- 大文字・小文字・数字を含む
- 過去5回のパスワードの再利用禁止
- パスワード強度メーター表示

## 2. フロー

### 2.1 ユーザー登録（Email & パスワード）

![alt text](../images/ユーザ登録フロー.png)

```mermaid
sequenceDiagram
    participant User
    participant Frontend (Next.js)
    participant Supabase Auth
    participant Backend (FastAPI)
    participant Database
    participant Audit Service

    User->>Frontend (Next.js): メール&パスワード入力
    Frontend (Next.js)->>Frontend (Next.js): 入力検証
    Frontend (Next.js)->>Supabase Auth: signInWithPassword()
    
    alt 認証失敗
        Supabase Auth-->>Frontend (Next.js): エラー（401）
        Frontend (Next.js)->>Database: 失敗回数を記録
        Frontend (Next.js)-->>User: エラーメッセージ表示
    else 認証成功
        Supabase Auth->>Database: セッション作成
        Supabase Auth-->>Frontend (Next.js): JWT Token + User Info
        Frontend (Next.js)->>Frontend (Next.js): Cookieに保存
        Frontend (Next.js)->>Backend (FastAPI): 監査ログ記録API
        Backend (FastAPI)->>Audit Service: ログイン記録
        Frontend (Next.js)->>Frontend (Next.js): ユーザー情報取得
        Frontend (Next.js)-->>User: ダッシュボードへリダイレクト
    end
```

### 2.2 ユーザー登録（SSO）

![alt text](../images/ユーザ登録フロー2.png)

```mermaid
sequenceDiagram
    participant User
    participant Frontend
    participant Supabase Auth
    participant Google OAuth
    participant Database
    participant Backend

    User->>Frontend: 「Googleでログイン」クリック
    Frontend->>Supabase Auth: signInWithOAuth('google')
    Supabase Auth->>Google OAuth: 認証リダイレクト
    User->>Google OAuth: Googleアカウントで認証
    Google OAuth->>Supabase Auth: 認証コード返却
    Supabase Auth->>Google OAuth: アクセストークン取得
    Supabase Auth->>Database: ユーザー作成/更新
    Supabase Auth->>Frontend: コールバックURL + Token
    Frontend->>Frontend: トークン保存
    Frontend->>Backend: ユーザー情報同期
    Frontend->>User: ダッシュボードへ
```

### 2.3 ログイン中

![alt text](../images/ユーザ登録フロー3.png)

```mermaid
sequenceDiagram
    participant Browser
    participant Next.js App
    participant Middleware
    participant Supabase Client
    participant Supabase Auth
    participant FastAPI
    participant Database

    Browser->>Next.js App: ページアクセス
    Next.js App->>Middleware: リクエスト処理
    Middleware->>Middleware: Cookieからトークン取得
    
    alt トークンが存在する
        Middleware->>Supabase Client: セッション検証
        Supabase Client->>Supabase Auth: トークン検証
        
        alt トークンが有効
            Supabase Auth-->>Supabase Client: ユーザー情報
            Supabase Client-->>Middleware: 認証成功
            Middleware->>Next.js App: リクエスト継続
            Next.js App->>Browser: ページ表示
        else トークンが期限切れ
            Supabase Auth-->>Supabase Client: 401 Unauthorized
            Supabase Client->>Supabase Auth: リフレッシュトークンで更新
            alt リフレッシュ成功
                Supabase Auth-->>Supabase Client: 新しいトークン
                Supabase Client->>Browser: Cookie更新
                Middleware->>Next.js App: リクエスト継続
            else リフレッシュ失敗
                Middleware->>Browser: ログインページへリダイレクト
            end
        end
    else トークンが存在しない
        Middleware->>Browser: ログインページへリダイレクト
    end
```
