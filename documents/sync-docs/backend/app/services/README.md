# Services

ビジネスロジックとサービス層。

## 主要サービス

### supabase.py
Supabaseサービス：
- Supabaseクライアント管理
- 認証サービスとの連携
- ストレージ操作

### user_service.py
ユーザー関連ビジネスロジック：
- ユーザー作成・更新
- プロフィール管理
- ロール管理

### post_service.py
投稿関連ビジネスロジック：
- 投稿の作成・編集
- 画像アップロード処理
- フィード生成ロジック

## サービス開発ガイドライン

1. ビジネスロジックをAPIから分離
2. トランザクション管理
3. エラーハンドリング
4. 再利用可能な関数設計
