# Backend Documentation

FastAPIを使用したバックエンドアプリケーションのドキュメント。

## ディレクトリ構造

- **app/** - FastAPIアプリケーションコード
  - **api/** - APIエンドポイント
  - **core/** - コア機能（セキュリティ、設定等）
  - **models/** - データベースモデル
  - **services/** - ビジネスロジック
- **tests/** - テストコード

## 主要技術スタック

- FastAPI
- PostgreSQL (Supabase)
- SQLAlchemy
- Pydantic
- Python 3.11+
