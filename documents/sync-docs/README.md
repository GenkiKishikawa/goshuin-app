# sync-docs

このディレクトリは、フロントエンドとバックエンドのディレクトリ構造を反映したドキュメント構造です。

## 構造

```
sync-docs/
├── frontend/     # フロントエンドコードのドキュメント
│   ├── app/      # Next.js App Routerのドキュメント
│   ├── components/ # コンポーネントのドキュメント
│   ├── hooks/    # カスタムフックのドキュメント
│   ├── lib/      # ユーティリティ関数のドキュメント
│   ├── providers/ # Context Providersのドキュメント
│   └── types/    # TypeScript型定義のドキュメント
└── backend/      # バックエンドコードのドキュメント
    ├── app/      # FastAPIアプリケーションのドキュメント
    └── tests/    # テストのドキュメント
```

各ディレクトリには、対応するコードディレクトリの機能と実装の詳細を記載したドキュメントが含まれています。
