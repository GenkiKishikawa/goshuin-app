# Library / Utilities

ユーティリティ関数とヘルパー。

## 主要ファイル

### supabase.ts
- Supabaseクライアントの設定
- PKCEフロー設定
- 自動トークンリフレッシュ

### auth-utils.ts
- 認証ユーティリティ関数
- ユーザーロール管理
- セッション検証
- パスワード強度チェック

### auth-error-handler.ts
- エラーハンドリング
- 日本語エラーメッセージ
- バリデーション

### mock-data.ts
- 開発用モックデータ
- 静的エクスポート用データ

## ユーティリティ開発ガイドライン

1. 純粋関数を優先
2. エラーハンドリングを含める
3. TypeScriptで型安全性を確保
4. テスト可能な設計
