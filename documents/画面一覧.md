# 画面洗い出し

# 画面一覧
| 画面名          | 目的・説明                | 備考                   |
| ------------ | -------------------- | -------------------- |
| ログイン画面       | SNSアカウントでのログイン／新規登録  | GoogleなどのOAuthボタンを配置 |
| 初回プロフィール登録画面 | 新規ユーザーに基本プロフィール入力を促す | 任意 or スキップ可能設計も検討    |
| プロフィール画面（自分用）   | 自分の投稿数・訪問神社数・いいね数・バッジ・ランキングを表示 | マイページ相当。編集ボタンも設置 |
| プロフィール画面（他ユーザー） | 他ユーザーのプロフィールと投稿一覧を表示           | フォローボタン付き        |
| プロフィール編集画面      | 名前・画像・自己紹介などの変更                |                  |
| 投稿作成画面    | 画像・本文・参拝日・神社・御朱印を入力   | 神社・御朱印選択 or 新規登録申請へ遷移 |
| 投稿詳細画面    | 投稿1件の全文・画像・いいね・コメント表示 | 神社・御朱印・参拝日など表示も含む     |
| タイムライン画面  | 全ユーザーの投稿を時系列順で表示      | ホーム画面の役割も担う           |
| 自分の投稿一覧画面 | 自身の投稿だけを表示・管理         | プロフィール画面内に統合も可        |
| 神社詳細画面          | 神社の基本情報・関連投稿・地図・御朱印一覧を表示 | タグ機能やナビ連携も検討可 |
| 御朱印詳細画面         | 1つの御朱印の画像・情報・投稿一覧を表示     |               |
| 神社／御朱印の新規登録申請画面 | 未登録の神社や御朱印をユーザーが登録申請     | 管理者レビュー用画面は別途 |
| ランキング画面 | 各種ランキング（訪問神社数・いいね数など）を表示 | タブで「週間／月間／年間／総合」を切替 |
| バッジ一覧画面 | 獲得済・未獲得バッジの一覧表示          | ゲーミフィケーション要素強化      |
| 地図画面       | 登録済み神社を地図上に表示（ピン表示） | 非ログインユーザーにも開放。詳細リンクあり |
| 神社・御朱印検索画面 | 投稿時や探索時に神社・御朱印を検索   | オートコンプリート機能付き推奨       |
| 通知一覧画面    | フォロー・いいね・コメントなどの通知一覧 | SNS体験を強化    |
| 設定画面      | ログアウト・通知設定・プライバシーなど  |             |
| ヘルプ・ガイド画面 | 使い方ガイド・投稿ルールなどを表示    | 初心者サポートにも活用 |
| 神社・御朱印の申請承認画面 | ユーザーからの新規登録申請を確認・承認 | 管理者専用。非公開でもOK |
